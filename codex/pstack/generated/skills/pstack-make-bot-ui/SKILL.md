# pstack: make-bot-ui

이 스킬은 사용자가 명시적으로 호출했을 때만 적용한다. 먼저 이 파일의 실제 경로를 확인하고 [Codex 어댑터](../../adapter.md)를 읽는다.

지원 상태: **unsupported**. Cursor Automations와 secret-request가 필수여서 Codex에서 실행하지 않습니다.

이 기능은 Cursor 전용이다. 어댑터의 제한을 설명하고 실행하지 않는다. 원본을 따라 자동화나 비밀 요청을 만들지 않는다.
